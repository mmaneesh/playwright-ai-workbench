# Decisions and Lessons

A staging area for framework-wide decisions and lessons, not an archive. Read the rows for your phase and `All` before starting a phase and before changing something already decided.

## Rules for this file

- **Status**: `Active`, `Promoted`, `Superseded` or `Retired`. A `Promoted` entry has become a rule in `CORE_PRINCIPLES.md` or a template (with a mechanical check where possible). A `Retired` entry's cause has been fixed. Both are deleted from this file; history stays in git.
- **Cap**: about 30 active entries. Going over forces a prune at the next phase sign-off.
- **Scope**: framework-wide only. Decisions about one application go in that target's workbook.
- **Phase**: the phase the entry applies to, or `All`.
- Only agreed decisions are recorded. Proposals stay in conversation until agreed.
